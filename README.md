# Bambinosit

## Description
Bambinosit est une plateforme web qui met en relation les parents avec des babysitters qualifiés.

## Objectif
Faciliter la recherche, la sélection et la réservation de babysitters.

## Fonctionnalités
-1.Module Utilisateurs & Authentification
2.Module Gestion des enfants
3.Module Gestion des activités
4. Module Inscriptions & Présences
5. Module Paiements & Facturation
6. Module Communication
7. Module Tableau de bord & Reporting
8. Module Paramétrage (admin uniquement)

## Méthodologie
Projet réalisé selon la méthode Scrum et les étapes du Design Thinking.
